# Hi, I'm Karim 👋

**Freelance full-stack developer from Cairo, and founder of [MK Studio](https://mk-studioeg.com).**

I build websites, web apps, and automation for businesses in Egypt, Saudi Arabia, the UAE, and Australia. I take projects from the brief to production: the frontend, the CMS behind it, the server, the deployment, and the support after launch.

Under MK Studio we've delivered **80+ projects since 2019**. Most of that code belongs to our clients and stays private, so the [case studies](https://github.com/KarimElGarhy/case-studies) show what we built and how.
